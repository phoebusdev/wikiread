# WikiRead

Add Wikipedia links to your EPUB footnotes. Perfect for philosophy, history, and academic texts.

## Features

- **Automatic footnote scanning** - Detects all footnotes in your EPUB
- **Smart term extraction** - Identifies philosophers, historical figures, concepts, and titles
- **Wikipedia linking** - Adds clickable ⓦ icons next to footnote numbers
- **Client-side processing** - Your files never leave your browser

## Development

```bash
npm install
npm run dev
```

## Deployment

Deploy to Vercel:

```bash
npx vercel
```

## Architecture

- **Next.js 14** - React framework with App Router
- **TypeScript** - Type-safe development
- **Tailwind CSS** - Utility-first styling
- **JSZip** - Client-side EPUB processing
- **Framer Motion** - Smooth animations
